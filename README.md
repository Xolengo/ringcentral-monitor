# ringcentral-monitor
Es un repositorio creado por Xolengo, donde se puede utilizar como un TEST de API REST para obtener información sobre llamadas en un tenant de RingCentral.

Tambien este resumen de llamadas se envía brevemente via SMS a un destino

Los orígenes y destinos no se pueden modificar, solo por el administrador.

De hecho no podrian ver las interacciones en plataformas de RingCentral ni en celulares, solamente podrían ver la metadata que genera en los Actions->Run Workflow NO MAS
